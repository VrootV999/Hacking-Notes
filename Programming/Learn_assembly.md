
## Stage 1 — Absolute Basics

- Purpose: Master registers, memory moves, arithmetic, and control flow.

    1. Hello World (Console Output)

    2. Add Two Numbers

    3. Compare Two Numbers and Branch

    4. Simple Loop Counter (0–9)

## Stage 2 — Working with Memory

-  Purpose: Learn addressing modes, data segments, and stack.
    5. String Reverser (manual loop over bytes)
    6. Manual Uppercase Converter
    7. Stack Push/Pop Demo
    8. Swap Two Variables Without Temporary Storage

## Stage 3 — Input & Output

- Purpose: Master reading and writing via BIOS or syscalls.
    9. Read a Character and Echo It
    10. Simple Calculator (2 numbers + operator)
    11. Read a String Until Enter is Pressed
    12. Text-based Menu System

## Stage 4 — Procedures & Control

- Purpose: Functions, calling conventions, modularity.
    13. Factorial (Recursive & Iterative)
    14. Fibonacci Sequence Generator
    15. Greatest Common Divisor (Euclidean Algorithm)

## Stage 5 — Bitwise Mastery

- Purpose: Bit shifts, masks, logic.
    16. Bitwise LED Pattern Simulator (if on microcontroller)
    17. Count Set Bits in a Byte
    18. Parity Checker

## Stage 6 — Advanced Memory & Data

- Purpose: Arrays, tables, and pointer-like addressing.
    19. Bubble Sort of an Array
    20. Search for a Value in Memory
    21. Lookup Table (e.g., ASCII to Morse Code)

## Stage 7 — System Interaction

- Purpose: Work with interrupts, BIOS, syscalls, and possibly hardware.
    22. BIOS-based Clock Reader
    23. Keyboard Scan Code Display
    24. Directly Writing to Video Memory (text mode)

## Stage 8 — Bigger Projects

- Purpose: Combine all concepts into multi-module programs.
    25. Mini Shell (read commands and run small routines)
    26.Tetris or Snake in Text Mode
    27. Simple Bootloader (prints a message)
    28. Mini OS Kernel with Keyboard Input & Screen Output
