# C/C++ Learning Project Roadmap

## Stage 1 — Basics
- Calculator (manual `scanf`/`printf`)
- Number guessing game (random from `rand()`)
- String manipulation without built-in functions

## Stage 2 — Pointers & Memory
- Custom string length function (`strlen`) without `<string.h>`
- Dynamic array implementation (using `malloc` and `realloc`)
- Manual memory copy function (`memcpy`)

## Stage 3 — Structs & Files
- Contact book (binary file storage using structs)
- CSV reader/writer
- Mini student database (sorting by name using `qsort`)

## Stage 4 — OOP / Advanced C++
- Bank account class (constructors, destructors)
- Shape hierarchy (inheritance, virtual functions)
- Complex number operator overloading

## Stage 5 — Algorithms
- Recursive maze solver
- Linked list, stack, queue from scratch
- Binary search tree with insert/search/delete

## Stage 6 — Advanced / System-Level
- Multithreaded downloader (C++ threads or `pthread`)
- Chat server (sockets)
- Memory pool allocator
