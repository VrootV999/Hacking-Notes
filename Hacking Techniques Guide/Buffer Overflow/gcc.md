# Types of protections used with its flag

- stack protector: `-fno-stack-protector` to disable
                 `-fstack-protector-all` to enable
- NX: `-z execstack` to disable
- PIE: `-no-pie` to disable

# other flags for later aid
- output file name: `-o <filename>` 
- bitness: `-m32 (or) -m64`
