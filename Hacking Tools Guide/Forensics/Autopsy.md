# Autopsy

## ✅ Features:

- Timeline analysis
- File carving
- Keyword searching
- Email, EXIF, SQLite parsing
- Hash matching & ingest modules

## Run autopsy
- autopsy then open browser http://localhost:9999/autopsy
- Start New Case → Add Data Source
- Disk image (.E01, .raw, .dd)
- Logical files/folders
