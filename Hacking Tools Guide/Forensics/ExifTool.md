
# Exiftools



|           COMMAND              |           Description               |
| -------------------------------|-------------------------------------|
| exiftool file.jpg              | get exif data of it                 |
| exiftool *.jpg                 | get exif data of all jpg in cwd     |
| exiftool -GPS* image.jpg       | only gps                            |
| exiftool -a -u -g1 image.jpg   | Show all tags including unknown     |
| exiftool -DateTimeOriginal file.jpg | creation date                  |
| exiftool -s -ImageWidth -ImageHeight file.jpg | show resolution      |
